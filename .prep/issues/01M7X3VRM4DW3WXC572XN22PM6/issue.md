## Requirement

Chord mode (ukulele) recognises tabs well but names only 9 chord types; anything else shows "?" (e.g. 0-0-1-0 = G C F A, an Fadd9). User (2026-11-20): focus on the ukulele, add more chords, and give the app enough music theory to say something about pretty much any combination of notes.

- Name any set of notes: a systematic namer (third, fifth, seventh, 6, extensions 9/11/13, alterations b9 #9 #11 b13 b5 #5, sus2/sus4, add, power chords, dim/dim7/m7b5/aug), choosing the simplest reading over all candidate roots; single notes and two-note intervals are described as such. Never "?".
- Say something about it: the main name, alternative names (0000 = Am7 / C6), each string's note with its role (R, 3, b7, 9 …) spelled correctly for the chord (Bb not A#), and the major keys that contain it with its Roman-numeral function (Fadd9: I in F, IV in C, V in Bb).
- More common ukulele shapes in the fingering prior; chord_eval covers extended chords too.
- History entries carry the analysis (basis for key detection later).
