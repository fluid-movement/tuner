`web/src/routes/+page.svelte` owns the engine (`startTuner` in `web/src/lib/audio/tuner-engine.ts`). A `sync()` helper stops the engine (tracks stopped, context closed) when `document.visibilityState !== 'visible'` or `!document.hasFocus()`, and starts it again on focus; it is called from window focus/blur and document visibilitychange. Blur is ignored while starting, since the permission prompt can take focus. A `paused` overlay explains the off microphone. The `strum = null` reset now runs only on analysis config changes, not on engine restarts.
Chord display: the page keeps `shownChord` (latest report naming a chord; a tentative chord that settles to none falls back to the last settled one) and passes it to `web/src/lib/components/ChordView.svelte` as `shown`; the status line still follows the latest `report`.
