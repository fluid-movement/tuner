User request (2026-11-24): a place to look up chords. Agreed: a fourth mode 'Chords' in the mode switch (Chord / Strum / String / Chords) that works without listening. Pick a chord with root pickers (12 roots) plus type pickers (major, minor, 7, maj7, m7, sus2, sus4, dim, aug, add9 and similar). The chord page shows the main ukulele shape as diagram and tab (same look as chord mode), alternative playable shapes up the neck, and notes and theory: each string's note with its role, the description, other names, and the keys it belongs to. Ukulele only for now; guitar later.
